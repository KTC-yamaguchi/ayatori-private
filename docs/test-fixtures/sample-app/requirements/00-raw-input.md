# 01 ブレスト回答（生入力）

**アプリ名:** テスト用タスク管理アプリ
**記録日時:** 2026-04-01

---

## ターゲットユーザー

10〜20名規模のスタートアップのエンジニアチーム。
フルリモートで働いており、Slack と GitHub を日常的に使っている。
タスクの粒度が細かく、スプリント単位で管理したいニーズがある。

## 解決したい課題

GitHub Issues と Notion を別々に使っており、ステータスが両方でバラバラになっている。
どこを見れば今何をやっているかわからず、毎朝スタンドアップで確認し直す手間がある。
エンジニアとPMが同じ画面を見て話せる場所が欲しい。

## 主要機能（MoSCoW）

### Must（必須）
- タスクの作成・編集・削除（タイトル・説明・担当者・期日・ステータス）
- カンバンボード表示（Todo / In Progress / Done の3列）
- チームメンバーへのタスクアサイン

### Should（重要）
- ラベル・タグによるフィルタリング
- 期日アラート（期日3日前に通知）

### Could（あれば良い）
- GitHub Issues との連携
- スプリント・マイルストーン管理

## 競合・参考アプリ

Linear が一番近い。シンプルで速い UI が好き。
Jira は機能が多すぎて使いにくい印象がある。
モバイルはあまり使わない想定なので Web メインで大丈夫。

## 制約条件

- 開発期間: 2 ヶ月（PoC）
- 予算: 外部 API の課金は最小限
- 技術スタック: Next.js + TypeScript + Supabase
- 開発人数: 2名のエンジニア

## 対応プラットフォーム

Web のみ。モバイル対応は今回スコープ外。
ブラウザは Chrome 最新版を想定。
