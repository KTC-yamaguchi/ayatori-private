# 06. 非機能要件（Non-Functional Requirements）

## 性能（Performance）

| ID | 要件 | 測定基準 |
|---|---|---|
| **NFR-01** | ホーム画面の初期読み込み時間 | 3 秒以内（ネットワーク速度: 4G） |
| **NFR-02** | 記事一覧の読み込み時間 | 2 秒以内（キャッシュ利用時） |
| **NFR-03** | 記事詳細ページの読み込み時間 | 2.5 秒以内 |
| **NFR-04** | 検索結果の表示時間 | 1.5 秒以内（ローカルインデックス検索） |
| **NFR-05** | 画像読み込みの遅延表示 | Lazy Loading で本文下部の画像は遅延読み込み |
| **NFR-06** | API レスポンスのタイムアウト | 5 秒超過時は「読み込み中...」表示 + リトライ提案 |

---

## セキュリティ・プライバシー

| ID | 要件 | 説明 |
|---|---|---|
| **NFR-10** | HTTPS 通信の必須化 | すべての通信を暗号化（v1 以降） |
| **NFR-11** | ユーザーデータ取得の最小化 | v1 ではユーザーアカウント不要。ブラウザ LocalStorage のみで履歴管理 |
| **NFR-12** | 外部 API キー管理 | サーバーサイドで秘密鍵を管理。クライアント側で公開しない |
| **NFR-13** | CORS ポリシー | 許可ドメイン明示 + クロスオリジン認証のセキュア実装 |
| **NFR-14** | キャッシュの有効期限 | ローカルキャッシュは 24 時間で無効化（自動削除） |

---

## 信頼性・エラーハンドリング

| ID | 要件 | 説明 |
|---|---|---|
| **NFR-20** | API 障害時の代替対応 | キャッシュデータを表示。キャッシュが無い場合はプレースホルダー表示 |
| **NFR-21** | ネットワーク遮断時の対応 | キャッシュがあれば表示可能。オフライン状態をユーザーに明示 |
| **NFR-22** | 画像取得失敗時の対応 | 代替テキスト表示 / プレースホルダー画像（Gray Out アイコン） |
| **NFR-23** | 検索失敗時の対応 | 「検索に失敗しました」と明示。再試行ボタンを提供 |
| **NFR-24** | 記事削除時の対応 | 404 ページで「この記事は利用できません」と表示 |
| **NFR-25** | 無限ループ防止 | API リトライ回数は最大 3 回で制限 |

---

## ユーザビリティ・アクセシビリティ

| ID | 要件 | 基準 |
|---|---|---|
| **NFR-30** | WCAG 2.2 AA レベル準拠 | すべての機能がキーボード操作可能。スクリーンリーダー対応 |
| **NFR-31** | コントラスト比（通常テキスト） | WCAG AA 基準 4.5:1 以上 |
| **NFR-32** | コントラスト比（大きいテキスト） | WCAG AA 基準 3:1 以上 |
| **NFR-33** | タップ領域のサイズ | 最小 44 × 44 pt（iOS）/ 48 × 48 dp（Android 基準） |
| **NFR-34** | テキスト拡大対応 | ブラウザのズーム 200% でも横スクロール不要 |
| **NFR-35** | 色だけに依存しない設計 | 区別に形状・パターン・テキストラベルを併用 |
| **NFR-36** | スクリーンリーダー対応 | ARIA ラベル / 見出し構造の適切な配置。読み上げテスト: NVDA / VoiceOver で 1 項目あたり ≤ 5 秒 |
| **NFR-37** | 画像の alt テキスト | すべての意味のある画像に代替テキストを付与 |
| **NFR-38** | フォーカス可視化 | Tab キー移動時にフォーカスが明確に表示される（輪郭線 ≥ 3px） |

## 互換性・環境対応

| ID | 要件 | 説明 |
|---|---|---|
| **NFR-40** | ブラウザ互換性 | Chrome, Safari, Firefox の最新 2 バージョン対応 |
| **NFR-41** | モバイルブラウザ | iOS Safari（15 以上）、Android Chrome（最新） |
| **NFR-42** | スマートフォンビューポート対応 | 320px 〜 390px（段階的対応） |
| **NFR-43** | レスポンシブデザイン | 768px をブレークポイントにした 3 段階レイアウト |

---

## メンテナンス・運用

| ID | 要件 | 説明 |
|---|---|---|
| **NFR-50** | ログ記録 | API 呼び出し・エラー・検索キーワードのログを サーバーサイドに記録（GDPR 対応を検討） |
| **NFR-51** | 更新頻度 | 記事データの更新は 1 日 1 回（UTC 00:00）に自動実行 |
| **NFR-52** | バージョン管理 | デプロイ時にメジャー・マイナー・パッチ番号を管理 |
| **NFR-53** | 本番環境の監視 | エラー率 / レスポンス時間を Sentry / Datadog で監視 |
