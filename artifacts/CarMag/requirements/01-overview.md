# 01. 概要（Overview）

## 目的・背景

自動車の所有者が、メンテナンスや季節の備えに関する**信頼できる情報に素早くアクセスできる**環境を提供する。

### 現状の課題

Google で「タイヤ交換時期」「冬の車準備」などを検索すると、ブログや広告記事が混在し、実際に必要な情報にたどり着くまでに時間がかかる。

### 解決方針

**カテゴリ化された記事をキュレーション形式で提供**することで、情報探索の時間を短縮する。カーセンサー等の車メディアサイトと同様に、記事を整理されたカテゴリから閲覧できるプラットフォーム。

---

## アプリの位置付け

| 項目 | 内容 |
|---|---|
| **アプリ名** | CarMag（カーマグ）— Car Magazine の略 |
| **提供形態** | Web ブラウザアプリ（PC・スマートフォン対応） |
| **主なユースケース** | メンテナンス情報、季節ごとの車の手入れ方法の検索・閲覧 |
| **ビジネスモデル** | 公開情報アクセス（v1 では管理画面なし、記事は外部 API / RSSフィード より取得） |
| **差別化ポイント** | 信頼できるメディア・API からキュレーションした記事のみを整理したカテゴリ導線 |

---

## ターゲットユーザー

- **主要ユーザー層**: 自動車を所有している個人（一般ドライバー）
- **年齢・属性**: 不問（初めての車所有者から経験者まで）
- **利用シーン**: 
  - タイヤ交換時期がいつか知りたい
  - 季節の変わり目に備えるべきことを調べたい
  - 新型車の情報を知りたい
  - 突然のトラブル時に対応法を探したい

---

## 成功指標（概要）

- **情報到達時間**: Google 検索と比較して 50% 削減
- **ユーザー満足度**: 「信頼できる情報が得られた」の回答率 ≥ 80%
- **リテンション**: 1 ヶ月以内の再訪問率 ≥ 60%（v1 PoC 段階での指標）
