# 03. ユーザーフロー（User Flow）

## アクター一覧

| アクター | 説明 |
|---|---|
| **一般ユーザー（訪問者）** | 記事検索・閲覧のみ。アカウント作成不要 |

---

## ロール別フロー

### ロール: 一般ユーザー

#### タスク 1: カテゴリから記事を探す（F-01）

**シナリオ: 「冬の車の準備について知りたい」**

```
ステップ 1: アプリを開く（ホーム画面）
  → 複数カテゴリが表示される

ステップ 2: 「季節対策」カテゴリをタップ / クリック
  → 季節対策の記事一覧が表示される

ステップ 3: 関連記事（例: 「冬のタイヤ交換ガイド」）をタップ / クリック
  → 記事詳細ページが表示される（タイトル・著者・公開日・本文・画像等）

ステップ 4: 記事を読む
  → 必要に応じてスクロール・戻るボタンで一覧に戻る
```

---

#### タスク 2: キーワード検索で記事を探す（F-02）

**シナリオ: 「特定の車種の冬対策を知りたい」**

```
ステップ 1: ホーム画面から検索ボックスをタップ / クリック
  → 検索フィールドが活性化される

ステップ 2: キーワード入力（例: 「プリウス 冬」）
  → 入力中に候補が表示される（オートコンプリート）

ステップ 3: 検索ボタンをタップ / 虹キーを押す
  → マッチした記事の一覧が表示される

ステップ 4: 結果から記事をタップ / クリック
  → 記事詳細ページが表示される
```

---

## エラーケース

| ID | シナリオ | トリガー | 対応 |
|---|---|---|---|
| **E-01** | API 連携失敗 | サーバー障害 / ネットワーク遮断 | ユーザーに「データを取得できません。後でお試しください」と通知。キャッシュがあれば前回のデータを表示 |
| **E-02** | 検索結果がない | 入力キーワードに該当記事なし | 「検索結果がありません。別のキーワードをお試しください」と表示 |
| **E-03** | ネットワークタイムアウト | 記事読み込み時間が長い | 「読み込み中...」と表示し、タイムアウト後は E-01 と同じ処理 |
| **E-04** | 画像読み込み失敗 | 記事内の画像の URL が無効 | 代替テキストを表示、または プレースホルダー画像を表示 |

## ナビゲーション構造

```
ホーム画面
├─ カテゴリ一覧（スクロール可能なカード UI）
│  ├─ カテゴリ「メンテナンス」をクリック
│  │  └─ 「メンテナンス」カテゴリの記事一覧
│  │     └─ 記事をクリック
│  │        └─ 記事詳細
│  └─ 他カテゴリ...
│
└─ 検索機能
   └─ キーワード入力
      └─ 検索結果一覧
         └─ 記事をクリック
            └─ 記事詳細
               └─ 「戻る」ボタン → 結果一覧に戻る
```

## デバイス別フロー

### Web ブラウザ（デスクトップ）

- マウス / トラックパッド操作
- キーボードナビゲーション対応（Tab キーで遷移可能）
- ウィンドウ 1440px 以上

### Web ブラウザ（スマートフォン）

- タップ操作
- スワイプでスクロール
- ウィンドウ 390px 以下（モバイルビューポート）
