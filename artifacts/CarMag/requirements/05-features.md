# 05. 機能一覧（Features）

## F-01: カテゴリ別の記事一覧・閲覧

| 項目 | 内容 |
|---|---|
| **機能 ID** | F-01 |
| **機能名** | カテゴリ別の記事一覧・閲覧 |
| **MoSCoW** | **MUST** |
| **優先度** | 1（最高） |
| **関連ユースケース** | UC-01, UC-03 |

### 説明

ユーザーがホーム画面でカテゴリ一覧を表示し、目的のカテゴリ（メンテナンス、季節対策、新車種情報等）を選択することで、そのカテゴリに属する記事の一覧を表示。その中から 1 件を選択して詳細を表示できる機能。

### 入力

- ユーザーのカテゴリ選択操作
- ホーム画面の表示リクエスト

### 処理

1. ホーム画面でカテゴリリストを取得・表示
2. ユーザーがカテゴリを選択
3. システムが外部 API / RSSフィード に対してそのカテゴリの記事データを問い合わせ
4. 取得した記事を一覧形式で表示
5. ユーザーが記事を選択
6. システムが記事詳細データを取得・表示

### 出力

- カテゴリ一覧画面
- カテゴリ別記事一覧画面
- 記事詳細画面

### データフロー

```
API / RSSフィード
      ↓
  カテゴリデータ取得
      ↓
  一覧表示（キャッシュに保存）
      ↓
  ユーザー選択
      ↓
  詳細データ取得
      ↓
  詳細表示
```

### 技術的実現方法

- **データ取得**: 外部 API または RSSフィード をポーリング / リアルタイム購読
- **キャッシング**: ブラウザ LocalStorage / IndexedDB で記事データを保存（更新頻度: 1 日 1 回推奨）
- **UI フレームワーク**: React / Vue など（技術スタック Step 5 で確定予定）

## F-02: 記事のキーワード検索

| 項目 | 内容 |
|---|---|
| **機能 ID** | F-02 |
| **機能名** | 記事のキーワード検索 |
| **MoSCoW** | **SHOULD** |
| **優先度** | 2 |
| **関連ユースケース** | UC-02, UC-03 |

### 説明

ユーザーが検索ボックスにキーワードを入力することで、記事データベース / API から該当する記事を絞り込んで表示できる機能。オートコンプリート機能により、入力中に候補を提示。

### 入力

- ユーザーのキーワード入力
- 検索実行操作

### 処理

1. ホーム画面に検索ボックスを配置
2. ユーザーがキーワードを入力
3. システムが入力中に（またはユーザー確定後に）キーワードにマッチする記事を API / キャッシュから検索
4. マッチ件数がない / タイムアウト時は代替メッセージを表示
5. 検索結果を一覧で表示
6. ユーザーが結果から記事を選択すると詳細表示

### 出力

- 検索候補（オートコンプリート）
- 検索結果一覧
- 記事詳細画面

### データフロー

```
ユーザー入力（キーワード）
      ↓
  オートコンプリート候補取得
      ↓
  検索ボタン実行 / Enter キー
      ↓
  API に検索クエリ送信
      ↓
  結果一覧取得・表示
      ↓
  ユーザー選択 → 詳細表示
```

### 検索対象

- 記事タイトル
- 記事本文（キーワード密度による）
- カテゴリタグ
- 著者名（オプション）

### 技術的実現方法

- **検索ライブラリ**: 全文検索エンジン（例: Lunr.js / Meilisearch）
- **キャッシング**: 記事データをオンメモリインデックス化（初回ロード時）
- **UI**: インクリメンタルサーチ + 検索履歴表示

## F-03: 記事詳細表示（共通機能）

| 項目 | 内容 |
|---|---|
| **機能 ID** | F-03 |
| **機能名** | 記事詳細表示 |
| **MoSCoW** | **MUST** |
| **優先度** | 1（最高） |
| **関連ユースケース** | UC-01, UC-02, UC-03 |

### 説明

選択された記事の全情報（タイトル・本文・著者・公開日・画像等）を表示。レスポンシブデザインで PC / スマートフォンの両方に対応。

### 表示要素

- **タイトル**: 記事の見出し
- **著者名**: 記事の作者 / メディア編集者
- **公開日 / 更新日**: ISO 8601 形式（例: 2026-07-17）
- **カテゴリタグ**: 記事が属するカテゴリ
- **本文**: テキスト + 画像の混合コンテンツ
- **画像**: 記事内のメイン画像 + 本文中の画像
- **出典**: 記事の提供元メディア名 + リンク
- **戻るボタン**: 一覧画面に戻る

### 出力

- 記事詳細ページ（HTML / React Component）

### レイアウト

- **デスクトップ（1440px+）**: 本文がコンテナ幅 800px 程度に制限、両脇に余白
- **スマートフォン（390px）**: 本文が画面全幅、マージン・パディングで内側に 16px 余白
