# 02. スコープ（Scope）

## MVP（Minimum Viable Product）機能一覧

| 機能 ID | 機能名 | 説明 | 優先度 | 対象 |
|---|---|---|---|---|
| **F-01** | **カテゴリ別記事一覧・閲覧** | メンテナンス / 季節 / 新車種などのカテゴリから記事を選んで閲覧できる | MUST | v1 |
| **F-02** | **記事のキーワード検索** | 車種名やキーワードで目的の記事を探せる | SHOULD | v1 |

---

## Phase 2 以降の機能（将来計画）

### Phase 2（v1.1 以降を検討）

- ユーザーアカウント・お気に入り機能
- 記事の評価・コメント機能
- カスタマイズされたカテゴリ表示（ユーザー関心度に基づくランキング）
- プッシュ通知（新着記事の通知）

### Phase 3（将来の拡張）

- 管理画面（記事のキュレーション・カテゴリ管理）
- ネイティブアプリ（iOS / Android）
- AI による記事推薦
- コミュニティ機能（ユーザー質問掲示板）

---

## やらないこと（スコープ外）

| 項目 | 理由 |
|---|---|
| **管理画面** | v1 では不要。記事データは外部 API / RSSフィード から自動取得 |
| **ユーザーアカウント** | v1 では実装しない。ブラウザキャッシュのみで暫定対応 |
| **ネイティブアプリ** | Web ブラウザで十分。スマートフォン対応は Web Responsive Design で実現 |
| **多言語対応** | v1 では日本語のみ |
| **オフライン対応** | ネットワーク接続前提 |
| **広告配信** | v1 では実装しない |

---

## スコープの境界

### "記事"の定義

外部 API / RSSフィード から取得した、自動車関連のニュース・ブログ記事。

**含まれるもの:**
- 信頼できる自動車メディア（カーセンサー、グーネット等）の記事
- 季節・メンテナンスなどのカテゴリで整理可能なもの

**含まれないもの:**
- 個人ブログ・掲示板投稿
- 広告コンテンツ
- SNS 投稿

### "カテゴリ"の定義

記事をユーザーの検索ニーズに合わせて分類するラベル。

**v1 対応カテゴリ例:**
- メンテナンス（タイヤ交換、オイル交換、バッテリー等）
- 季節対策（冬の備え、夏の対策等）
- 新車種情報
- トラブル対応
- 運転ノウハウ

※ カテゴリの具体列挙は 07-data-definition.md で詳述
