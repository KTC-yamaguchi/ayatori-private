# 04. ユースケース（Use Cases）

## UC-01: カテゴリから記事を閲覧する

| 項目 | 内容 |
|---|---|
| **UC ID** | UC-01 |
| **ユースケース名** | カテゴリから記事を閲覧する |
| **関連機能** | F-01（カテゴリ別記事一覧・閲覧） |
| **アクター** | 一般ユーザー |
| **前提条件** | ホーム画面が表示されている、ネットワーク接続がある |

### 基本フロー

1. ユーザーがホーム画面のカテゴリリストから、興味のあるカテゴリ（例: 「季節対策」）を選択する
2. システムが当該カテゴリに属する記事の一覧を取得する（外部 API / RSSフィード から）
3. 記事一覧が画面に表示される（タイトル・著者・公開日・サムネイル画像等）
4. ユーザーが記事を 1 件選択する
5. システムが記事の詳細情報を取得・表示する（本文・画像・関連情報等）
6. ユーザーが記事を読む
7. ユーザーが「戻る」ボタンを押すか、別のカテゴリを選択する

### 代替フロー

**A1: API がデータを返さない場合**
- 手順 2 で、システムがエラーハンドラーを実行
- ユーザーに「データを読み込めません」と表示
- キャッシュがあればそれを表示

**A2: ユーザーが記事一覧から戻りたい場合**
- 手順 6 中に「ホームに戻る」ボタンを押す
- ホーム画面に戻る

### 後条件

- ユーザーが記事情報を閲覧した
- 記事データがブラウザキャッシュに保存される（オフライン表示への備え）

## UC-02: キーワードで記事を検索する

| 項目 | 内容 |
|---|---|
| **UC ID** | UC-02 |
| **ユースケース名** | キーワードで記事を検索する |
| **関連機能** | F-02（記事のキーワード検索） |
| **アクター** | 一般ユーザー |
| **前提条件** | ホーム画面が表示されている、ネットワーク接続がある |

### 基本フロー

1. ユーザーがホーム画面の検索ボックスをクリック / タップする
2. 検索フィールドが活性化される
3. ユーザーがキーワードを入力する（例: 「プリウス 冬」）
4. システムが入力中に検索候補を表示する（オートコンプリート）
5. ユーザーが検索ボタンを押すか Enter キーを押す
6. システムが外部 API / RSSフィード から該当キーワードにマッチする記事を検索する
7. 検索結果が一覧で表示される
8. ユーザーが結果から記事を選択する
9. 記事詳細が表示される
10. ユーザーが読み終わり、検索結果に戻る / 新しい検索を行う

### 代替フロー

**A1: キーワードに該当する記事がない場合**
- 手順 7 で、システムが「検索結果がありません」メッセージを表示
- 代替キーワード提案がある場合は表示

**A2: 検索がタイムアウトする場合**
- 手順 6 中にタイムアウト発生
- ユーザーに「検索中...」と表示した後、「検索に失敗しました」と通知

### 後条件

- 検索キーワードと結果が記録される（将来の分析用途）
- 検索結果がキャッシュされる

## UC-03: 記事詳細を読む

| 項目 | 内容 |
|---|---|
| **UC ID** | UC-03 |
| **ユースケース名** | 記事詳細を読む |
| **関連機能** | F-01, F-02（共通） |
| **アクター** | 一般ユーザー |
| **前提条件** | 記事一覧または検索結果が表示されている |

### 基本フロー

1. ユーザーが記事一覧 / 検索結果から 1 件の記事をクリック / タップする
2. システムが記事詳細ページを読み込む
3. 記事の詳細情報が表示される：
   - タイトル
   - 著者名
   - 公開日 / 更新日
   - カテゴリタグ
   - 本文（テキスト + 画像）
   - 記事の出典（メディア名）
4. ユーザーがスクロールして本文を読む
5. 読み終わったら、「戻る」ボタンをクリック / タップ
6. 一覧画面に戻る

### 代替フロー

**A1: 記事が削除または利用不可の場合**
- 手順 2 で 404 エラーが返される
- ユーザーに「この記事は利用できません」と表示
- 一覧に戻るボタンを提示

### 後条件

- ユーザーが記事を閲覧した
- 記事閲覧履歴が記録される（v2 での推薦機能実装時に利用）
