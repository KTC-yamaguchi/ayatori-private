アプリ名: MyGreenStep 記録日時: 2026-04-16

ターゲットユーザー

何気なく日常生活を送っている一般の人。家事、買い物、通院、散歩など普通の生活をしている。環境問題のニュースを見て気になったり、子どもに聞かれて答えられなかったりして「何かしないと」と思っている。環境にいいことをしたい気持ちはあるが、具体的に何をすればいいかわかっていない。光熱費の高騰や気候変動への漠然とした不安がある。

解決したい課題

  • 自分に何ができるかわかっていない
  • 自分一人が行動を変えても意味がないのではないかと思ってしまっている
  • 「エコ」が漠然としていて、具体的なアクションに落とし込めない

    • → その人の行動の影響を可視化し、「自分一人でも変化を起こせる」と実感してもらいたい

主要機能（MoSCoW）

Must（必須）

  • 初回アンケートで生活パターンを把握（住環境、移動手段、家族構成など）
  • アンケート結果に基づいた、パーソナライズされた具体的アクションの提案
  • アクションを実行したときの影響（CO2削減量など）の可視化・フィードバック
  • アプリ使用前と後で、どれだけ環境に良い行動ができているかのビフォー・アフター表示

Should（重要）

  • 科学的データに基づいた信頼性のある数値の提示

Could（あれば良い）

  • ゲーミフィケーション（今は不要、将来的に検討）
  • コミュニティ機能（今は不要、将来的に検討）

競合・参考アプリ

特になし

  • 開発期間: 未定
  • 予算: 未定
  • 技術スタック: 未定

  • アクション記録時（アクション単位型）: アクションを記録した瞬間に「このアクションで○○g削減」と即時フィードバック。その日の合計も表示

01 プロジェクト概要

1.1 目的

本プロジェクトは、個人の環境保護行動を支援するモバイルアプリケーション「MyGreenStep」を開発することを目的とする。ユーザーが日常生活で実践できるエコアクションを提案し、その効果をCO2削減量として可視化することで、「自分一人の行動でも環境に貢献できる」という実感を提供する。

1.2 背景

気候変動への関心が高まる一方で、多くの人が「自分一人が行動しても何も変わらない」という無力感を抱えている。環境問題に関する情報は溢れているが、個人レベルで「何をすればいいか」「その行動にどれだけの効果があるか」が分かりにくい状態にある。

この課題を解決するため、以下のアプローチを採用する。

  • ユーザーのライフスタイルに合わせたパーソナライズされたアクション提案により、「何をすればいいか」の迷いを解消する。
  • CO2削減量のビフォー・アフター可視化により、個人の行動が持つ意味をデータで証明する。

1.3 ターゲットユーザー

属性内容
ペルソナ環境問題に関心はあるが、具体的な行動に踏み出せていない一般生活者
年齢層20代〜40代を主要ターゲットとする
ITリテラシースマートフォンの基本操作（アプリのインストール・利用）が可能なレベル
動機「何かしたいが、何をすればいいかわからない」「自分の行動に意味があるのか知りたい」

1.4 解決する課題

P-002自分一人の行動に意味がないと感じるCO2削減量のビフォー・アフター可視化による効果の証明

1.5 アプリの位置づけ

  • 製品カテゴリ: 個人向け環境保護支援アプリ（モバイル）
  • 対応プラットフォーム: iOS / Android（クロスプラットフォーム開発: Flutter / React Native / KMP のいずれか）
  • 開発フェーズ: MVP（最小限の実用可能な製品）
  • データ方針: MVPでは一般的なCO2排出平均値を仮置きし、将来的に権威ある公的データソースに差し替える
  • 認証方式: メールアドレスによるアカウント登録

02 スコープ定義

2.1 MVP（リリース対象）

MVPでは、ユーザーが「登録→アンケート回答→アクション提案の確認→実行記録→効果の可視化」という一連の体験を完了できることを最低限の要件とする。

スコープID機能領域含まれる内容
S-001アカウント管理メールアドレスによる新規登録、ログイン、ログアウト、パスワードリセット
S-002ライフスタイルアンケート初回登録後のアンケート（住環境、移動手段、家族構成、食生活等）、再回答機能
S-003アクション提案アンケート結果に基づくパーソナライズされたエコアクション一覧の提示
S-004アクション詳細各アクションの説明（何をするか、なぜ効果的か、期待されるCO2削減量）
S-005アクション記録ユーザーが実行したアクションのチェックイン（実施日時の記録）
S-006CO2削減量可視化アクション実行前後のCO2排出量比較（ビフォー・アフター）、累積削減量の表示
S-007プロフィール管理ユーザー情報の表示・編集、アンケート再回答によるアクション提案の更新
S-008CO2データ一般的なCO2排出平均値を仮データとして使用（権威あるデータへの差替を前提とした設計）

MVP対象エコアクション例

アクションカテゴリ具体例
エネルギー再生可能エネルギー電力プランへの切替、省エネ家電の選択
食生活週1回のノーミートデー（肉を食べない日）、地産地消の食材購入
住環境窓への断熱シート貼付
移動2km以内の移動を徒歩または自転車に変更
消費環境配慮企業の製品を優先的に選択

2.3 スコープ外（やらないこと）

以下の機能・要素は、本プロジェクトのすべてのフェーズにおいてスコープ外とする。対応が必要になった場合は、別プロジェクトとして立ち上げる。

除外ID項目除外理由
EXC-001リアルタイム環境データ連携気象データや大気質データのリアルタイム取得は、技術的複雑性とコストが高く、MVPの価値提供に必須ではない
EXC-002IoTデバイス連携スマートメーターや家電との連携は、ハードウェア依存性が高く、ターゲットユーザーの導入障壁となる
EXC-003カーボンオフセット購入金銭取引を伴う機能は、法的要件・決済基盤の整備が必要であり、MVPの範囲を超える
EXC-004位置情報トラッキング常時位置情報取得はプライバシー懸念が大きく、ユーザー離脱の要因となりうる
EXC-005AI画像認識レシートや食品の画像認識によるアクション自動記録は、精度担保が困難でMVPに適さない

7.5 ベースライン算出ロジック

ユーザーの「アクション実行前の推定CO2排出量（週間）」を算出するロジック。F-006のビフォー・アフター比較に使用する。

基準値

日本の1世帯あたり平均CO2排出量: 約2,740kg/年（環境省「家庭部門のCO2排出実態統計調査」参考値）

→ 週間換算: 2,740 ÷ 52 ≒ 52.7kg/週

内訳と補正ロジック

排出カテゴリ年間排出量の構成比週間ベースラインアンケートによる補正条件
電力約50%（1,370kg/年）26.3kg/週energy_provider = 再エネプラン → 0kg/週に補正
ガス・給湯約15%（410kg/年）7.9kg/週showerhead_replaced = はい → 7.9 × 0.8 = 6.3kg/週に補正
自動車約20%（550kg/年）10.6kg/週transport_mode = 公共交通機関 or 自転車 or 徒歩 → 0kg/週に補正
食事約10%（275kg/年）5.3kg/週diet_type = 菜食中心 → 5.3 × 0.6 = 3.2kg/週に補正
その他（消費・廃棄物等）約5%（135kg/年）2.6kg/週補正なし

算出手順

  1. 基準値 52.7kg/週 からスタート
  2. アンケート回答に応じて各カテゴリの値を補正
  3. 補正後の合計値がそのユーザーのベースライン（週間推定排出量）
  4. アンケート再回答（F-008経由）時はベースラインを再算出し、以降の比較に使用する
  5. 再算出前のベースライン値は履歴として保持し、過去の比較データに遡及適用しない

算出例

ユーザーA: 通常電力プラン、シャワーヘッド未交換、自家用車通勤、バランス型食事 → 26.3 + 7.9 + 10.6 + 5.3 + 2.6 = 52.7kg/週（平均的な排出量）

ユーザーB: 再エネプラン契約済み、節水シャワーヘッド済み、公共交通、バランス型食事 → 0 + 6.3 + 0 + 5.3 + 2.6 = 14.2kg/週（すでに削減済みのユーザー）

7.6 CO2削減量データ方針

MVP（Phase 1）

  • ActionMaster.co2_reduction_kg は静的な固定値としてアプリ内に保持する
  • 数値の根拠は 05-features.md セクション5.2「アクションマスタデータ」に記載の算出根拠に基づく
  • 「推計値」と記載のあるアクション（ACT-007〜009）はMVP時点では概算データを使用し、アプリ内で「参考値」と明示する
  • データ更新時は data_version をインクリメントする
