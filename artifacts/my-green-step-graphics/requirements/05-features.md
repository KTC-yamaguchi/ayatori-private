# 05 機能要件

## 5.1 機能一覧

### F-001: メールアカウント登録

| 項目 | 内容 |
|------|------|
| 機能ID | F-001 |
| 機能名 | メールアカウント登録 |
| 説明 | ユーザーがメールアドレスとパスワードを入力し、新規アカウントを作成する |
| 入力 | メールアドレス（RFC 5322準拠）、パスワード（8文字以上、英数字混在） |
| 処理 | 1. メールアドレスの形式を検証する 2. パスワードの強度を検証する 3. メールアドレスの重複を確認する 4. アカウントレコードを作成する 5. 確認メールを送信する 6. ユーザーが確認リンクをクリックしたらアカウントを有効化する |
| 出力 | 登録成功画面（初回アンケートへの導線を含む）、またはエラーメッセージ（重複・形式不正・パスワード強度不足） |
| MoSCoW | Must |
| 関連UC | UC-001 |

### F-002: ログイン／ログアウト

| 項目 | 内容 |
|------|------|
| 機能ID | F-002 |
| 機能名 | ログイン／ログアウト |
| 説明 | 登録済みユーザーがメールアドレスとパスワードで認証し、アプリにアクセスする。またはセッションを終了する |
| 入力 | ログイン: メールアドレス、パスワード。ログアウト: ログアウトボタンのタップ |
| 処理 | ログイン: 1. 入力されたメールアドレスとパスワードの組み合わせを検証する 2. 認証トークンを発行する 3. ホーム画面に遷移する。ログアウト: 1. 認証トークンを無効化する 2. ログイン画面に遷移する |
| 出力 | ログイン成功: ホーム画面表示。ログイン失敗: エラーメッセージ（「メールアドレスまたはパスワードが正しくありません」）。ログアウト成功: ログイン画面表示 |
| MoSCoW | Must |
| 関連UC | UC-001 |

### F-003: 初回ライフスタイルアンケート

| 項目 | 内容 |
|------|------|
| 機能ID | F-003 |
| 機能名 | 初回ライフスタイルアンケート |
| 説明 | ユーザーの生活スタイルを把握するためのアンケートを実施し、パーソナライズの基礎データを収集する |
| 入力 | 以下の選択式回答: 住居形態（戸建て／マンション／アパート）、居住人数（1人〜5人以上）、主な移動手段（自家用車／公共交通機関／自転車／徒歩）、通勤通学距離（2km未満／2-10km／10km以上）、食生活傾向（肉中心／バランス型／菜食寄り）、電力契約種別（一般／再エネプラン／不明）、環境配慮への関心度（低／中／高） |
| 処理 | 1. 各設問の回答を順番に取得する 2. 未回答の必須項目がないか検証する 3. 回答内容をユーザープロフィールに紐づけて保存する 4. 回答データをアクション提案エンジン（F-004）に渡す |
| 出力 | アンケート完了画面（「あなたに合ったアクションを提案します」メッセージ）、おすすめアクション一覧画面への遷移リンク |
| MoSCoW | Must |
| 関連UC | UC-002 |

### F-004: パーソナライズされたアクション提案エンジン

| 項目 | 内容 |
|------|------|
| 機能ID | F-004 |
| 機能名 | パーソナライズされたアクション提案エンジン |
| 説明 | アンケート回答に基づき、ユーザーに最適なエコアクションを優先順位付きで提案する |
| 入力 | ユーザーのアンケート回答データ（F-003の出力）、エコアクションマスタデータ（アクション定義・適用条件・期待CO2削減量）、アクション適用ルール定義（アンケート回答条件→対象アクションの対応表） |
| 処理 | 1. アンケート回答からユーザープロファイルを生成する 2. アクション適用ルール表に基づきマッチングを実行する: (a) energy_provider ≠ 再エネプラン → 「再エネ電力プランへの切替」を提案 (b) showerhead_replaced = いいえ → 「節水シャワーヘッド導入」を提案 (c) beef_frequency ≥ 1回/週 → 「週1回の牛肉→鶏肉/豚肉」を提案 (d) online_shopping = はい → 「宅配便の置き配指定」を提案 (e) transport_mode = 自家用車 AND commute_distance < 2km → 「2km以内は徒歩/自転車に変更」を提案 (f) housing_type = any AND ac_filter_cleaning < 月2回 → 「エアコンフィルター月2回清掃」を提案 3. 適用可能アクションを期待CO2削減量の大きい順にソートする 4. 上位10件を提案リストとして生成する |
| 出力 | パーソナライズされたアクション提案リスト（各アクションにつき: アクション名、概要説明、期待CO2削減量、難易度ラベル） |
| MoSCoW | Must |
| 関連UC | UC-003 |

### F-005: アクション実行記録（チェックイン）

| 項目 | 内容 |
|------|------|
| 機能ID | F-005 |
| 機能名 | アクション実行記録（チェックイン） |
| 説明 | ユーザーが実行したエコアクションを日単位で記録する |
| 入力 | 対象アクションID、実施日（デフォルト: 当日） |
| 処理 | 1. 対象アクションIDの存在を検証する 2. 同一アクション・同一日の重複記録がないか確認する 3. 実行記録レコードを作成する（アクションID、ユーザーID、実施日、記録日時） 4. 累積CO2削減量を再計算する |
| 出力 | 記録完了メッセージ（「記録しました！ 今回の削減量: X.X kg-CO2」）、更新された累積削減量サマリー |
| MoSCoW | Must |
| 関連UC | UC-004 |

### F-006: CO2削減量の影響度可視化

| 項目 | 内容 |
|------|------|
| 機能ID | F-006 |
| 機能名 | CO2削減量の影響度可視化 |
| 説明 | ユーザーのアクション実行によるCO2削減効果を、3つの場面に応じた形式で表示する |
| 入力 | ユーザーID、表示コンテキスト（ホーム画面／詳細画面／アクション記録直後） |
| 処理 | 1. ユーザーの全アクション実行記録を取得する 2. アンケート回答からアクション実行前のCO2排出量（ベースライン）を算出する。ベースライン算出ロジック: 日本の1世帯あたり平均CO2排出量（約2,740kg/年 ÷ 52週 ≒ 52.7kg/週）を基準とし、アンケート回答で補正する（例: energy_provider = 再エネプラン契約済みなら電力由来分（約50% ≒ 26kg/週）を除外、transport_mode = 公共交通機関なら自家用車由来分を除外） 3. アクション実行後の推定CO2排出量を算出する 4. 表示コンテキストに応じてデータを整形する: (A)ホーム画面用: 累積削減量＋わかりやすい換算（杉の木○本分）を算出 (B)詳細画面用: 週間排出量のビフォー・アフター比較＋変化率（○%削減）を算出。ベースライン＝初回アンケートから推定した週間排出量、今＝ベースラインからその週に記録したアクションの削減量を差し引いた値 (C)アクション記録直後: 当該アクションのCO2削減量＋その日の合計削減量を算出 5. アンケート再回答（F-008経由）時はベースラインも再算出する |
| 出力 | (A)ホーム画面: 累積CO2削減量（kg単位）＋杉の木換算、今月の増分 (B)詳細画面: 週間排出量の棒グラフ比較（以前の推定 vs 今週の推定）＋削減率パーセント表示 (C)アクション記録時: 即時フィードバック（「このアクションで○○g削減」）＋本日の合計 |
| MoSCoW | Must |
| 関連UC | UC-005 |

### F-007: アクション詳細表示

| 項目 | 内容 |
|------|------|
| 機能ID | F-007 |
| 機能名 | アクション詳細表示 |
| 説明 | 個別のエコアクションについて、実施方法・効果の根拠・期待削減量を詳しく表示する |
| 入力 | アクションID |
| 処理 | 1. アクションIDに対応するマスタデータを取得する 2. ユーザーのアンケート回答に基づき、当該ユーザーにとっての期待削減量を個別計算する 3. 表示用データを整形する |
| 出力 | アクション詳細画面: アクション名、カテゴリ、具体的な実施手順（ステップ形式）、なぜ効果的かの説明文、当該ユーザーの期待CO2削減量（kg-CO2/月）、難易度ラベル、チェックイン（記録）ボタン |
| MoSCoW | Should |
| 関連UC | UC-003, UC-004 |

### F-008: プロフィール編集

| 項目 | 内容 |
|------|------|
| 機能ID | F-008 |
| 機能名 | プロフィール編集 |
| 説明 | ユーザーが自身のプロフィール情報を確認・編集する。アンケートの再回答によりアクション提案を更新できる |
| 入力 | 変更対象フィールド（表示名、メールアドレス）、またはアンケート再回答データ（F-003と同一形式） |
| 処理 | 1. 変更内容のバリデーションを実施する 2. メールアドレス変更の場合は再確認メールを送信する 3. プロフィール情報を更新する 4. アンケート再回答の場合は、回答データを上書き保存し、アクション提案エンジン（F-004）を再実行する |
| 出力 | 更新完了メッセージ、アンケート再回答の場合は更新されたアクション提案リスト |
| MoSCoW | Should |
| 関連UC | UC-006 |

### F-009: パスワードリセット

| 項目 | 内容 |
|------|------|
| 機能ID | F-009 |
| 機能名 | パスワードリセット |
| 説明 | パスワードを忘れたユーザーがメールアドレスを使用してパスワードを再設定する |
| 入力 | リセット要求時: 登録済みメールアドレス。再設定時: リセットトークン（メール内リンクに含まれる）、新しいパスワード（8文字以上、英数字混在） |
| 処理 | 1. 入力されたメールアドレスの登録有無を確認する 2. 一意のリセットトークン（有効期限: 24時間）を生成する 3. リセットリンクを含むメールを送信する 4. ユーザーがリンクをクリック後、トークンの有効性を検証する 5. 新しいパスワードの強度を検証する 6. パスワードを更新し、既存の全セッションを無効化する |
| 出力 | リセット要求時: 「パスワード再設定メールを送信しました」メッセージ（登録有無に関わらず同一メッセージ）。再設定完了時: 「パスワードを変更しました。ログインしてください」メッセージとログイン画面への遷移 |
| MoSCoW | Must |
| 関連UC | UC-001 |

## 5.2 アクションマスタデータ（MVP初期データ）

以下はMVPに投入するエコアクションの初期データ一覧。CO2削減量は日本の一般的なライフスタイルに基づく推計値であり、出典を明記する。将来的に環境省・IPCC等の権威あるデータに差し替える前提で設計する。

| アクションID | アクション名 | カテゴリ | CO2削減量 | 単位 | 難易度 | 算出根拠 | 適用条件（target_survey_keys） |
|---|---|---|---|---|---|---|---|
| ACT-001 | 再エネ電力プランへの切替 | エネルギー | 36.5 | kg/週（≒1,900kg/年） | 1（簡単） | 家庭CO2の約50%は電力由来。再エネプランに切替で電力由来CO2をほぼゼロにできる | energy_provider ≠ 再エネプラン |
| ACT-002 | 節水シャワーヘッド導入 | 住まい | 1.9 | kg/週（≒100kg/年） | 1（簡単） | 4人家族でシャワー使用量20%削減時の給湯ガス・水道ポンプのエネルギー削減分 | showerhead_replaced = いいえ |
| ACT-003 | 週1回の牛肉→鶏肉/豚肉 | 食事 | 2.0 | kg/週（≒104kg/年） | 1（簡単） | 牛肉100gの生産CO2は鶏肉の約10倍。週1回の置換で年間104kg削減 | beef_frequency ≥ 1回/週 |
| ACT-004 | エアコンフィルター月2回清掃 | 住まい | 0.6 | kg/週（≒30kg/年） | 1（簡単） | フィルター清掃で冷房約4%・暖房約6%の消費電力削減 | ac_filter_cleaning < 月2回 |
| ACT-005 | 宅配便の置き配指定 | 買い物 | 0.2 | kg/週（≒10kg/年） | 1（簡単） | 再配達1回あたり約0.5kg-CO2。月数回の利用で年間約10kg削減 | online_shopping = はい |
| ACT-006 | 2km以内の移動を徒歩/自転車に | 移動 | 1.8 | kg/週（≒95kg/年） | 2（普通） | 自家用車→自転車で約130g-CO2/km削減。週5日×片道2kmで計算 | transport_mode = 自家用車 AND commute_distance < 2km |
| ACT-007 | 窓に断熱シートを貼る | 住まい | 1.0 | kg/週（≒50kg/年） | 2（普通） | 窓からの熱損失を約30%低減し、冷暖房エネルギーを削減（推計値） | housing_type = any |
| ACT-008 | 地産地消の食材を優先購入 | 食事 | 0.5 | kg/週（≒25kg/年） | 2（普通） | 輸送距離の短縮によるフードマイレージ削減（推計値） | diet_type = any |
| ACT-009 | 環境配慮企業の製品を選択 | 買い物 | 0.3 | kg/週（≒15kg/年） | 2（普通） | 環境配慮型サプライチェーンによる間接的CO2削減（推計値） | online_shopping = any OR housing_type = any |

> **注記**: 「推計値」と記載のあるアクション（ACT-007〜009）はMVP時点では概算データを使用。Phase 2でデータソースを特定し精度を向上させる。
