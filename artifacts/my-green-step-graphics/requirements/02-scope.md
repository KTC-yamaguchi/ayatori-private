# 02 スコープ定義

## 2.1 MVP（リリース対象）

MVPでは、ユーザーが「登録→アンケート回答→アクション提案の確認→実行記録→効果の可視化」という一連の体験を完了できることを最低限の要件とする。

| スコープID | 機能領域 | 含まれる内容 |
|------------|----------|------------|
| S-001 | アカウント管理 | メールアドレスによる新規登録、ログイン、ログアウト、パスワードリセット |
| S-002 | ライフスタイルアンケート | 初回登録後のアンケート（住環境、移動手段、家族構成、食生活等）、再回答機能 |
| S-003 | アクション提案 | アンケート結果に基づくパーソナライズされたエコアクション一覧の提示 |
| S-004 | アクション詳細 | 各アクションの説明（何をするか、なぜ効果的か、期待されるCO2削減量） |
| S-005 | アクション記録 | ユーザーが実行したアクションのチェックイン（実施日時の記録） |
| S-006 | CO2削減量可視化 | アクション実行前後のCO2排出量比較（ビフォー・アフター）、累積削減量の表示 |
| S-007 | プロフィール管理 | ユーザー情報の表示・編集、アンケート再回答によるアクション提案の更新 |
| S-008 | CO2データ | 一般的なCO2排出平均値を仮データとして使用（権威あるデータへの差替を前提とした設計） |

### MVP対象エコアクション例

| アクションカテゴリ | 具体例 |
|--------------------|--------|
| エネルギー | 再生可能エネルギー電力プランへの切替、省エネ家電の選択 |
| 食生活 | 週1回のノーミートデー（肉を食べない日）、地産地消の食材購入 |
| 住環境 | 窓への断熱シート貼付 |
| 移動 | 2km以内の移動を徒歩または自転車に変更 |
| 消費 | 環境配慮企業の製品を優先的に選択 |

## 2.2 Phase 2以降（将来検討）

以下の機能は、MVPリリース後のユーザーフィードバックおよび事業判断に基づき、Phase 2以降で検討する。

| 将来ID | 機能領域 | 概要 | 検討時期 |
|--------|----------|------|----------|
| FUT-001 | ゲーミフィケーション | バッジ、レベル、連続記録ストリークなどの達成報酬 | Phase 2 |
| FUT-002 | コミュニティ | ユーザー間の削減量ランキング、グループチャレンジ | Phase 2 |
| FUT-003 | SNS共有 | 自分の削減成果をSNSでシェアする機能 | Phase 2 |
| FUT-004 | 企業版 | 企業・組織単位でのCO2削減管理ダッシュボード | Phase 3 |
| FUT-005 | 権威データ連携 | 環境省・IPCCなど公的機関のCO2排出係数データとの連携 | Phase 2 |
| FUT-006 | 多言語対応 | 日本語以外の言語サポート | Phase 3 |

## 2.3 スコープ外（やらないこと）

以下の機能・要素は、本プロジェクトのすべてのフェーズにおいてスコープ外とする。対応が必要になった場合は、別プロジェクトとして立ち上げる。

| 除外ID | 項目 | 除外理由 |
|--------|------|----------|
| EXC-001 | リアルタイム環境データ連携 | 気象データや大気質データのリアルタイム取得は、技術的複雑性とコストが高く、MVPの価値提供に必須ではない |
| EXC-002 | IoTデバイス連携 | スマートメーターや家電との連携は、ハードウェア依存性が高く、ターゲットユーザーの導入障壁となる |
| EXC-003 | カーボンオフセット購入 | 金銭取引を伴う機能は、法的要件・決済基盤の整備が必要であり、MVPの範囲を超える |
| EXC-004 | 位置情報トラッキング | 常時位置情報取得はプライバシー懸念が大きく、ユーザー離脱の要因となりうる |
| EXC-005 | AI画像認識 | レシートや食品の画像認識によるアクション自動記録は、精度担保が困難でMVPに適さない |
