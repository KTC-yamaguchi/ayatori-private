# 06 非機能要件

本ドキュメントは ISO/IEC/IEEE 29148:2018 に準拠し、MyGreenStep アプリの非機能要件を定義する。

---

## 6.1 性能要件

| ID | 要件 | 目標値 | 計測条件 |
|----|------|-------|---------|
| NFR-P-01 | アプリ起動時間 | 3 秒以内（コールドスタート） | 対応端末の中央値スペックにて計測 |
| NFR-P-02 | API レスポンスタイム | 2 秒以内（95 パーセンタイル） | 通常負荷時 |
| NFR-P-03 | 画面遷移時間 | 1 秒以内 | アプリ内画面間の遷移 |
| NFR-P-04 | アクション記録の保存完了 | 1 秒以内 | ボタン押下から完了表示まで |
| NFR-P-05 | ダッシュボードのグラフ描画 | 2 秒以内 | 1 年分のデータ保持時 |
| NFR-P-06 | アプリサイズ | 50 MB 以下 | 初回インストール時 |
| NFR-P-07 | メモリ使用量 | 150 MB 以下 | 通常利用時のピーク値 |

---

## 6.2 セキュリティ要件

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-S-01 | 通信の暗号化 | すべての通信を HTTPS（TLS 1.2 以上）で暗号化する |
| NFR-S-02 | パスワードの保存 | bcrypt（コストファクター 10 以上）でハッシュ化して保存する。平文での保存・ログ出力を禁止する |
| NFR-S-03 | 認証方式 | JWT（JSON Web Token）を使用する。アクセストークンの有効期限は 1 時間、リフレッシュトークンは 30 日とする |
| NFR-S-04 | 個人データの暗号化 | メールアドレス・アンケート回答などの個人データは、保存時に AES-256 で暗号化する |
| NFR-S-05 | パスワード要件 | 8 文字以上、英字・数字をそれぞれ 1 文字以上含むこと |
| NFR-S-06 | ログインの保護 | 連続 5 回のログイン失敗でアカウントを 15 分間ロックする |
| NFR-S-07 | セッション管理 | ログアウト時にサーバー側でトークンを無効化する |
| NFR-S-08 | データ削除 | ユーザーがアカウント削除を要求した場合、30 日以内に全データを物理削除する |
| NFR-S-09 | 入力値の検証 | すべてのユーザー入力に対し、サーバー側でバリデーションを実施する（SQL インジェクション・XSS 対策） |

---

## 6.3 可用性要件

| ID | 要件 | 目標値 |
|----|------|-------|
| NFR-A-01 | サービス稼働率 | 99.5%（月間） |
| NFR-A-02 | 計画メンテナンス | 月 1 回、最大 2 時間。事前にアプリ内通知で告知する |
| NFR-A-03 | 障害復旧時間（RTO） | 4 時間以内 |
| NFR-A-04 | データ復旧ポイント（RPO） | 24 時間以内 |
| NFR-A-05 | オフライン対応 | アクション記録をローカルに一時保存し、接続復旧後に自動同期する |

---

## 6.4 エラーハンドリング方針

| ID | 方針 | 詳細 |
|----|------|------|
| NFR-E-01 | ユーザー向けメッセージ | 技術的な用語を使わず、次に何をすればよいかを案内する |
| NFR-E-02 | 自動リトライ | ネットワークエラー時は最大 3 回（5 秒間隔）自動リトライする |
| NFR-E-03 | エラーログ | すべてのエラーをサーバーに送信し、発生日時・エラー種別・画面名を記録する |
| NFR-E-04 | クラッシュレポート | アプリクラッシュ時にレポートを自動送信する（ユーザー同意後） |
| NFR-E-05 | グレースフルデグラデーション | 外部サービス障害時もアプリの基本機能（記録の閲覧）は利用可能とする |

## 6.5 対応環境

| ID | 項目 | 対応範囲 |
|----|------|---------|
| NFR-ENV-01 | iOS | iOS 15 以上 |
| NFR-ENV-02 | Android | Android 10（API レベル 29）以上 |
| NFR-ENV-03 | 画面サイズ | 4.7 インチ〜6.7 インチ（スマートフォンのみ。タブレットは MVP 対象外） |
| NFR-ENV-04 | 画面向き | 縦向きのみ対応 |
| NFR-ENV-05 | 言語 | 日本語のみ（MVP） |
| NFR-ENV-06 | クロスプラットフォーム | Flutter または React Native を採用し、iOS・Android を単一コードベースで開発する |

---

## 6.6 アクセシビリティ

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-ACC-01 | 準拠基準 | WCAG 2.1 AA レベルを目標とする |
| NFR-ACC-02 | 色のコントラスト比 | テキストと背景のコントラスト比を 4.5:1 以上とする |
| NFR-ACC-03 | スクリーンリーダー対応 | すべての操作可能な要素にアクセシビリティラベルを設定する |
| NFR-ACC-04 | フォントサイズ | OS のフォントサイズ設定に追従する（最大 200% まで対応） |
| NFR-ACC-05 | タッチターゲット | 操作可能な要素のタッチ領域を 44×44 ポイント以上とする |
| NFR-ACC-06 | 色のみに依存しない表現 | 情報の伝達を色のみに依存せず、アイコン・テキストを併用する |

---

## 6.7 データバックアップ

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-BK-01 | バックアップ頻度 | データベースの自動バックアップを 1 日 1 回実施する |
| NFR-BK-02 | バックアップ保持期間 | 30 日間保持する |
| NFR-BK-03 | リストア検証 | 月 1 回、バックアップからのリストアテストを実施する |
| NFR-BK-04 | バックアップ保管場所 | 本番環境とは異なるリージョンに保管する |
